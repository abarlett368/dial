# 使用帮助

[首页](../README.zh-CN.md) | [English](USER-GUIDE.md)

## 首次启动与更新

请将 `dial.exe` 放在固定文件夹中运行。没有配置时，程序会自动打开设置；
选择“保存”后才会将配置写入磁盘。更新前请从通知区域菜单退出 dial，
再替换程序。替换程序不会删除当前用户的设置。

如果已开启登录时启动，需要移动程序，请先关闭该选项并保存，再移动程序，
最后在新位置重新开启并保存，更新启动路径。

## 打开、选择与关闭轮盘

默认快捷键为 **Ctrl+Tab**。在设置中单击快捷键旁的“设置”按钮，
按下所需组合键，再保存。录制期间原快捷键会暂时注销；
单击“取消”或按 Esc 可放弃录制。若组合键与其他程序冲突，dial 会提示错误。

轮盘默认显示在鼠标所在显示器的工作区中央。开启鼠标位置选项后，
轮盘会尽量在鼠标附近显示，并限制在当前工作区内。

- 单击扇区执行操作。
- 右方向键或上方向键按顺时针选择下一项；左方向键或下方向键选择上一项。
  按 Enter 执行。
- 鼠标移出轮盘会重置选择。
- 按 Esc、单击圆心、单击外部或失去焦点均会关闭轮盘。
  隐藏圆心后，原圆心位置仍支持单击关闭。

没有项目或没有已启用项目时，不会打开空轮盘。

## 编辑项目

选中列表中的项目后修改其内容。“添加”“删除”和上下箭头用于管理项目。
第一个项目位于正上方，其余按列表顺序沿顺时针排列，最多支持 16 项。
禁用的项目仍会保存，但不会显示在轮盘上。未保存的编辑不会影响当前轮盘。
“保存”按钮会预览当前选择的强调色；列表使用中性灰选中态，不会因选中而改变行尺寸。

| 操作类型 | 用途 |
| --- | --- |
| 启动应用 | 选择可执行文件或已安装的应用，可按支持情况填写参数 |
| 打开文件或文件夹 | 使用 Windows 打开文档或文件夹 |
| 打开网址 | 填写绝对网址或应用支持的 URI |
| 系统命令 | 选择内置 Windows 操作 |
| 运行命令或脚本 | 执行你信任的命令 |
| 粘贴文本 | 将片段写入剪贴板，再发送 Ctrl+V |

应用选择器包含受支持的 Microsoft Store 应用。应用标识和 URI
快捷方式不支持请求提权；受支持的可执行文件可以逐项开启管理员运行，
执行时由 Windows 显示 UAC 提示，dial 本身保持普通权限。

名称和自定义文字图标最多支持 64 个字符，也可以使用图片文件作为图标。
请保证外部目标和图标文件路径有效。只配置你理解并信任的命令和脚本。
关机、重启、注销等系统命令会影响当前工作，请勿把它们当作测试操作。

电子邮件示例使用 `you@example.com`，请自行替换。
粘贴文本会覆盖剪贴板；Windows 可能阻止普通权限程序向更高权限窗口发送输入。

## 外观

可选择浅色或深色主题、强调色，以及英文或简体中文。
四种布局分别为：外图标内标签（默认）、内图标外标签、仅标签和仅图标。
圆心可以隐藏；显示时会根据当前选中名称在限定尺寸内自适应。
极长单词仍可能被省略，以免文字越过扇区边界。

选中扇区不会改变主题原本的字体颜色。浅色主题的配色适配深色文字，
深色主题的配色适配白色文字。浅色 Windows 蓝按要求保留 #357EC7，
作为固定配色中文字对比度较低的唯一例外。亚克力选中效果通过染色提高鲜艳度，
保持基本相同的背景透过比例；背后窗口仍会影响最终显示的颜色。
高对比度模式继续使用 Windows 的系统选中文字颜色。

配色第二项为“Windows 强调色”，会跟随当前 Windows 强调色。
在系统中修改强调色后，已打开的轮盘也会自动更新，无需重启。
此项会在必要时调整底色明暗，让文字保持主题原有的颜色并维持可读性。

Windows 的透明效果、高对比度和动画设置会影响显示。
系统材质不可用时使用不透明扇区，但扇区间隙仍保持透明。

## 设置、备份与重置

正常配置路径为 `%LOCALAPPDATA%\dial\settings.json`，
可在文件资源管理器地址栏中输入该路径。设置按用户保存，不自动同步，
也不写入可执行文件。首次保存之前不会创建配置目录或文件。

- **备份：** 退出 dial，将配置文件复制到安全位置。
- **恢复：** 退出 dial，用兼容的备份替换配置文件，然后重新启动。
- **重置：** 退出 dial，将配置文件重命名为备份文件。重新启动后会载入八个默认示例，
  保存后生成新配置。
- **重新加载：** 通知区域菜单中的对应命令读取磁盘配置，不会保存尚未提交的编辑。

已保存的空列表会保持为空。损坏的配置会报错，不会被默认配置静默覆盖；
可以恢复备份，或重命名文件后重置。
配置可能包含私人文本片段、命令参数和本地路径，请勿上传至源码仓库。

## 常见问题与移除

| 问题 | 检查方法 |
| --- | --- |
| 快捷键无效 | 处理快捷键冲突，确认存在已启用的项目 |
| 关闭设置后仍在运行 | 属于正常行为，请从通知区域菜单退出 |
| 没有亚克力效果 | 检查 Windows 透明效果、高对比度、远程会话和图形环境 |
| 操作执行失败 | 检查目标是否存在，以及权限、参数和应用安装状态 |
| 动画中文字略软 | 小数像素缩放仍需灰度抗锯齿；出入场已不再缩放整层位图缓存 |
| 无法读取或保存配置 | 检查文件格式、访问权限及是否被其他程序锁定 |

诊断时可运行 `dial.exe --settings` 打开设置。
`dial.exe --config "C:\path\settings.json"` 可指定独立配置，
但需要先退出已有实例；同一 Windows 会话只运行一个实例。

移除时，先关闭登录时启动并保存，再退出程序并删除可执行文件。
如需清除个人配置，备份后删除 `%LOCALAPPDATA%\dial`。
程序没有需要卸载的服务或安装程序。
